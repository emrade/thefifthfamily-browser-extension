# Game changes

A record of each time the game changed under the extension: what changed,
when (to the minute, from the archive), the evidence, what it broke or
shifted in the extension, and what was done about it. Use it when a number
stops matching ("this didn't use to happen") to check whether it has been
seen before.

One file per change, named `YYYY-MM-DD-<feature>-<what>.md` by the date the
change hit the archive. Each one links back to the feature's main doc in
`docs/`, and that doc links forward to it.
